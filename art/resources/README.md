# Resource-card art

Final artwork for the six resource cards—the objects a hero draws on to cast.
Each image is named for its ink and is kept separate from `art/index.json`,
which maps ordinary card IDs to their artwork.

| File | Ink |
|---|---|
| `red.png` | Red · Fire |
| `amber.png` | Amber · Arcane |
| `green.png` | Green · Nature |
| `blue.png` | Blue · Frost |
| `purple.png` | Purple · Shadow |
| `steel.png` | Steel · Physical |
